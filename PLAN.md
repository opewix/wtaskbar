# WTaskbar — панель задач Windows для macOS

Цель: замена Dock, максимально похожая на панель задач Windows по виду и поведению — в темах
Windows 10 (тёмная), Vista и XP.

## Решения

- **Стек:** Swift + AppKit, SwiftPM без Xcode, как у WExplorer. `scripts/bundle.sh` собирает `build/WTaskbar.app`.
- **Фоновая программа** (`LSUIElement`): ни значка в Dock, ни строки меню.
- **Окна панели — `nonactivatingPanel`**: щелчок по панели и ввод в «Пуске» не отбирают активность у
  программы пользователя. Иначе повторный щелчок по активной программе не мог бы её «свернуть».
- **Dock прячем как uBar:** автоскрытие с задержкой 1000 с; исходное значение запоминаем, при выходе возвращаем.
- **«Свернуть» = скрыть программу** (⌘H): на Mac у программы нет единого «свёрнутого» состояния.
- **Окна программ — через Accessibility**, без него панель работает, но без списка окон и «стопки».
- **Темы** (`Theme/Skins.swift`): тема рисует панель и задаёт размеры, раскладку делает `TaskbarView`.
  У «Пуска» две раскладки: Windows 10 и классическая (XP/Vista) — `ClassicStartMenu.swift`.
- **Неподвижность при смене стола** — закрытый API SkyLight: окно панели живёт только в своём
  пространстве, а не на рабочих столах. Без API — обычное `canJoinAllSpaces`.
- **Масштаб** — разница рамки и границ вида (`setBoundsSize`): раскладка и отрисовка остаются в
  логических точках темы, окно на экране больше или меньше. Векторная графика не размывается.
- **Графика своя:** глифы «Пуска», поиска, «Представления задач» рисуются кодом; значков Microsoft нет.
- **Проверка вида:** `WTaskbar -snapshot <папка>` рисует панель, «Пуск» и календарь в PNG — без
  разрешения на запись экрана.
