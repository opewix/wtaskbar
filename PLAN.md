# WTaskbar — панель задач Windows для macOS

Цель: замена Dock, максимально похожая на панель задач Windows по виду и поведению — в темах
Windows 10 (тёмная), Vista и XP.

## Решения

- **Стек:** Swift + AppKit, SwiftPM без Xcode, как у WExplorer. `scripts/bundle.sh` собирает `build/WTaskbar.app`.
- **Фоновая программа** (`LSUIElement`): ни значка в Dock, ни строки меню.
- **Окна панели — `nonactivatingPanel`**: щелчок по панели и ввод в «Пуске» не отбирают активность у
  программы пользователя. Иначе повторный щелчок по активной программе не мог бы её «свернуть».
- **Dock прячем как uBar:** автоскрытие с задержкой 1000 с; исходное значение запоминаем, при выходе возвращаем.
- **«Свернуть» = скрыть программу** (⌘H): на Mac у программы нет единого «свёрнутого» состояния.
- **Окна программ — через Accessibility**, без него панель работает, но без списка окон и «стопки».
- **Темы** (`Theme/Skins.swift`): тема рисует панель и задаёт размеры, раскладку делает `TaskbarView`.
  У «Пуска» две раскладки: Windows 10 и классическая (XP/Vista) — `ClassicStartMenu.swift`.
- **Неподвижность при смене стола** — закрытый API SkyLight: окно панели живёт только в своём
  пространстве, а не на рабочих столах. Без API — обычное `canJoinAllSpaces`.
- **Масштаб** — разница рамки и границ вида (`setBoundsSize`): раскладка и отрисовка остаются в
  логических точках темы, окно на экране больше или меньше. Векторная графика не размывается.
- **Графика своя:** глифы «Пуска», поиска, «Представления задач» рисуются кодом; значков Microsoft нет.
- **Проверка вида:** `WTaskbar -snapshot <папка>` рисует панель, «Пуск» и календарь в PNG — без
  разрешения на запись экрана.

## Сделано (0.17)

- [x] «Закрыть» в меню кнопки закрывает окна, а не программу, как в Windows: на кнопке окна —
      только это окно, на кнопке группы — «Закрыть окно» или «Закрыть все окна». Это самый нижний
      пункт; выход из программы — над ним, «Завершить <программа>»
- [x] Кнопки только окон текущего рабочего стола, как в Windows 10 (выключается в параметрах).
      Стол окна — `SLSCopySpacesForWindows` по номеру окна из закрытой `_AXUIElementGetWindow`;
      полноэкранные окна видны на всех столах, свёрнутые — только на своём (до 0.21 — на всех);
      программа, все окна которой на других
      столах, пропадает с панели, а закреплённая остаётся значком, будто не запущена. Accessibility окон других столов не отдаёт
      вовсе — такая программа для неё «без окон»; их ищем по списку WindowServer
      (`appsWithWindowsElsewhere`: обычный уровень, от 150×150, стол известен и не текущий).
      Проверка: `open -n WTaskbar.app --args -dumpWindows <файл>`
- [x] Программа без окон (закрыл последнее окно Finder) на панели не запущена, как в Windows:
      закреплённая — значком, незакреплённая пропадает. До работающей без окон программы (плеер)
      с панели теперь не добраться — только «Пуск» или Dock
- [x] Щелчок по значку программы, которая запущена, но окон на этом столе не имеет, открывает новое
      окно здесь: панель нажимает в её меню «Новое окно» / New Window (нет — пункт с ⌘N) через
      Accessibility и выводит вперёд это окно, когда оно появится (до 2 с), — не программу: её главное
      окно на другом столе, и macOS перешла бы туда. Окно ищется во всех экземплярах: у WExplorer
      «Новое окно» — новый процесс. Нет такого пункта — как раньше, запуск через
      NSWorkspace (macOS может перейти на стол с её окном)
- [x] Экземпляры одной программы — одна кнопка (место в порядке общее, по пути программы): у WExplorer
      «Новое окно» — новый процесс, и раньше второй процесс вставал отдельной кнопкой в конец, а закреплённый
      значок оставался рядом и уводил на стол первого. Кнопка «запущена», если окна здесь есть хоть у одного
      экземпляра; окна группы — от всех таких экземпляров (`TaskItem.apps`, `Window.pid`)
- [x] Щелчок по запущенной программе выводит вперёд её окно этого стола (в фокусе → любое не свёрнутое →
      свёрнутое), а не программу через NSWorkspace: та при нескольких экземплярах или окнах на разных
      столах могла увести на другой стол
- [x] Shift и щелчок по кнопке, а также пункт с именем программы в меню кнопки — ещё одно окно программы
      («Новое окно» в её меню через Accessibility); вперёд выходит окно, которого до нажатия не было.
      Нет такого пункта или программа не запущена — как обычный щелчок. Второй процесс чужой программы
      не запускаем: не всякая это переносит
- [x] Повторный щелчок по активной кнопке по умолчанию сворачивает окно (было — скрывает программу
      со всеми окнами); в фокусе ли окно, при щелчке спрашивается заново, а не берётся с прошлого опроса
- [x] Кнопки стола назначения — сразу по окончании свайпа, не дожидаясь анимации (около секунды; macOS
      меняет `Current Space` только в её конце). `DesktopSwipe` слушает жест Dock (`CGEvent.tapCreate`,
      тип 30, свой поток), по концу жеста решает направление (скорость, иначе половина пути) и
      `Desktops.predict` считает текущим соседний стол дисплея под курсором, пока macOS его не подтвердит;
      не подтвердила за 2 с — возврат. Окна стола назначения берутся из памяти об окнах других столов
      (`refreshWindows`); программа, чьи окна там ещё не видели, — одной кнопкой до конца анимации.
      Проверка перехвата: `-dumpWindows` пишет `swipeTap=listen|default|none`
- [x] Активная кнопка при смене стола — тоже сразу: macOS меняет активную программу только в конце
      анимации, и до того на новом столе подсвечивалась кнопка прежней. Теперь на время перехода
      активным считается верхнее окно стола назначения (`WindowList.stack`, `TaskbarModel.predictedFront`),
      пока macOS не сообщит об активации
- [x] То же для клавиш: `DesktopSwipe` слушает нажатия и сверяет код клавиши и модификаторы с системными
      сочетаниями Mission Control из `com.apple.symbolichotkeys` (79 и 81 — стол левее и правее, по
      умолчанию ⌃← / ⌃→; 118… — «Переключиться на рабочий стол N», ⌃1…⌃9, по умолчанию выключены);
      сочетания перечитываются раз в 10 с, повтор при удержании не считается
- [x] Шрифт как в Windows (`Fonts` в `Theme.swift`, выключается в параметрах): Tahoma — шрифт интерфейса
      XP, входит в macOS; в Vista и Windows 10 — Segoe UI, если пользователь поставил его сам, иначе та же
      Tahoma. Шрифтов Microsoft в программе по-прежнему нет. Крупные светлые цифры часов над календарём —
      системным шрифтом (у Tahoma нет светлого начертания); курсив «пуск» в XP — наклоном. Окно
      параметров — системным шрифтом, это окно macOS
- [x] Кнопки с подписями в Windows 10: зазор между соседними, фон только у активной и под курсором,
      полоска фоновой запущенной короче кнопки (раньше полоски сливались в одну линию, а у запущенных
      был свой фон)
- [x] Щелчок колёсиком по кнопке — ещё одно окно программы (как Shift и щелчок)
- [x] Щелчок по сгруппированной кнопке с несколькими окнами на этом столе открывает список окон
      (в Windows — эскизы), а не выводит одно из них наугад
- [x] «Показать рабочий стол» в меню панели
